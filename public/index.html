Location Drive MCP Server

Connect Claude, Cursor, or any MCP-compatible AI client to the global Location Drive POI database — 350M+ places, graded building polygons, brand intelligence, and premium data packs.

Endpoint mcp.locationdrive.com/mcp npm @locationdrive/mcp 8 read-only tools

Hosted — no install

Streamable HTTP with your own API key as a Bearer header. Plan gating, quotas, and usage metering apply exactly as with direct API calls. Get a free key →

Claude Code

claude mcp add --transport http locationdrive https://mcp.locationdrive.com/mcp \
  --header "Authorization: Bearer ld_live_YOUR_KEY"

Cursor — .cursor/mcp.json

{
  "mcpServers": {
    "locationdrive": {
      "url": "https://mcp.locationdrive.com/mcp",
      "headers": { "Authorization": "Bearer ld_live_YOUR_KEY" }
    }
  }
}

Local — runs on your machine

Requires Node 18+. Same tools, same key, over stdio.

Claude Desktop — claude_desktop_config.json

{
  "mcpServers": {
    "locationdrive": {
      "command": "npx",
      "args": ["-y", "@locationdrive/mcp"],
      "env": { "LOCATIONDRIVE_API_KEY": "ld_live_YOUR_KEY" }
    }
  }
}

Claude Code

claude mcp add locationdrive -e LOCATIONDRIVE_API_KEY=ld_live_YOUR_KEY \
  -- npx -y @locationdrive/mcp

Tools

FREE+search_places

Search the global POI database by name or keyword.

FREE+find_nearby

Distance-sorted places around a coordinate.

FREE+get_place_details

Full record by ID; premium fields (EV, fuel, menus, hotels) on eligible plans.

FREE+get_place_context

LLM-ready summary + structured record for one place.

STARTER+get_building_polygon

GeoJSON footprint with A–E accuracy grade and area.

STARTER+find_building_at_point

Reverse lookup — which building contains this coordinate.

Store counts by country, open-now, coverage, average rating.

FREE+data_coverage

Per-country POI counts and polygon coverage stats.
